SKILL.md 给的是骨架。这里是各阶段可直接照做的深度 rubric。

<a name="p0"></a>
## P0 · 研究设计层

### 问题类型 → 设计映射

| 研究问题长这样 | 类型 | 适配设计 | 商业调研做法 |
|---|---|---|---|
| "X 是什么 / 有哪些玩家" | 探索性 | 定性 | 案头扫描 + 5-10 深访 + 专家访谈 |
| "A 和 B 有没有关系 / 哪个更重要" | 相关性 | 定量观察 | 二手数据相关分析；需量化时小样本问卷 |
| "做了 X 是否真导致 Y" | 因果 | 实验/准实验 | A/B、前后对比+对照组、自然实验 |
| "用户用 X 是什么体验/卡哪" | 现象/体验 | 定性 | 深度访谈、可用性观察 |
| "X 怎么一步步变成今天" | 过程/历时 | 案例/纵向 | → P3 纵轴 |
| "把 X 整体摸清" | 综合 | 混合 | → P3 全轴 |

### 证据标准（什么算够，必须可判定）

信源可信度分级：S 一手数据 > A 权威机构/学术/监管 > B 行业报告/头部媒体 > C 一般媒体/百科 >
D 营销稿/利益相关自述/AI未验摘要。**结论强度不超过其最弱关键证据。C/D 当 A/S 用 = 翻车头号原因。**

停止条件示例（可判定）：
- 定性访谈：信息饱和（连续 2-3 个无新主题即停，经验 5-15 人）
- 二手研究：关键结论 ≥3 个独立信源交叉（独立=不引同一原始源）；数字回 S/A 级
- 专家：单一专家=假设非结论，须找利益相反两方 + 二手印证

### 效度威胁清单（逐条过，命中的 + 对冲写进 spec）

| 类 | 威胁 | 对冲 |
|---|---|---|
| 样本/选择 | 幸存者偏差 | 主动找 ≥3 个"同做法但失败"对照 |
| 样本/选择 | 选择偏差 | 明确总体边界，跨渠道取样 |
| 测量/认知 | 确认偏差 | 开工前写"什么证据会证伪我"，主动找 |
| 测量/认知 | 社会赞许偏差 | 问具体行为/最近一次，不问态度 |
| 来源/利益 | 数据源利益相关 | 标注每个源立场，找利益相反方 |
| 因果 | 混淆变量/反向因果 | 列第三变量、设对照组、看时间先后 |

<a name="p3"></a>
## P3 · 双轴分析（横纵分析法完整版）

### 纵轴（历时 Diachronic）— 报告主体，篇幅最重

- **起源追溯**：诞生背景、基于什么技术/理念/需求、核心推动者之前做过什么、当时行业环境、促成诞生的关键事件
- **诞生节点**：首次发布/成立时间、最初形态与定位、与现在的差异
- **演进历程**：按时间梳理所有关键节点（版本/融资/团队/转型/架构/规模里程碑/合作收购/危机争议）
- **决策逻辑还原**：每个关键节点为什么选A不选B？当时约束？哪些早期决策"锁定"了后来走向难逆转？
  什么机制让它越走越深（网络效应/生态绑定/技术栈）
- **阶段划分**：自然分几个阶段，每阶段核心特征 + 核心矛盾

### 横轴（共时 Synchronic）

先判竞品场景：
- **A 无直接竞品**：分析为什么没有（品类太新/壁垒太高/市场太小）+ 未来从哪冒竞争者 + 间接替代
- **B 少量（1-2）**：逐一深入对比
- **C 充分（3+）**：取代表 3-5 个深对，其余简提

对比维度：核心差异（技术路线/形态/商业模式/目标用户/优劣/定价）+ **用户真实口碑**（社区评价、被提最多的优缺点，
讲清每个竞品"活成了什么样"）+ 生态位 + 趋势判断。

### 横纵交汇（精华段，非缩写）

1. 历史如何塑造当下竞争位置
2. 主要竞品放时间线上对比，起源/演变路径差异如何导致今天各自特点
3. 今天每个优势的历史根源
4. 今天每个劣势的历史根源（当初"好决策"是否成今天包袱）
5. 未来三剧本：最可能 / 最危险 / 最乐观，各有逻辑支撑

### 类型适配

产品→版本迭代/技术路线/增长曲线｜公司→创始团队/融资/战略转向｜
概念→起源(谁提的)/流行/争论演变｜人物→职业轨迹/关键决策/言论变化。

<a name="p4"></a>
## P4 · 五层萃取判层

| 层 | 别名 | 一句话 | 典型糊弄词 |
|---|---|---|---|
| L1 | 碎片 raw | 原始未加工素材 | "一堆资料" |
| L2 | 特征 feature | 分类/分层/打标签/维度拆解 | "top 3"、"分 A/B/C"、"5 大维度" |
| L3 | 观点 viewpoint | 有态度有判断（好/不好+为什么） | 万能正确话（"要聚焦用户"） |
| L4 | 洞察 insight | **观点的观点**——捅灭其他观点的那一个 | — |
| L5 | 单/框架 dan | 能**稳定复现**洞察的方法（E=mc² 级） | — |

判层规则：取**最低命中层**（保守，避免高估）。检测到糊弄词 → 主动提示"可能停在 L2"。

炼丹产出（--deep）：
- `insight_candidates`：每条带 `falsifiability`（什么情况下这条不成立）。至少 1 条。
- `dan_candidates`：能形成一句话公式才叫单 + 3 个以上复用场景。材料不够诚实声明"需要 XXX"。

**闸门**：洞察/方案/结论类产出不到 L4 不许标"完成"，除非用户显式豁免。

<a name="p5"></a>
## P5 · 失真校验 + 实证证伪

### 失真声明表（产物开头先读，逐条标 已解决/待解决/不可解读）

1. **口径失真（头号）**：gross vs 扣费净值、宣传口径 vs 真实口径。经验：手册/纪要数字易被放大，
   量级可达数倍。凡引用须标来源；结论一律以最硬数据（带标签真值）为准。
2. **归属歧义**：PDF 图例顺序 ≠ 表格行/列顺序、标签错配。用不会错的锚点（如基准指数）
   跨源交叉校验反推归属，不凭图例顺序认列。
3. **时点失真**：不同源 as-of 日期不同（如 xlsx 出表 3月、PDF 出表 5月），同指标差异源于时点非矛盾。
   标注各源截止日，差异归因 as-of。

### 根因铁律（gstack）

**无根因不下结论。** 修症状=打地鼠，每个不治本的修复让下一个 bug 更难找。
四阶段：收集症状 → 读代码/材料追路径 → 查近期变更（回归=根因在 diff）→ 可复现再下判断。

### 实证证伪层（最高阶）

用因子级/持仓级/一手**真数据**回检 P0–P4 的假说，**允许并要求推翻自己**。
- 归因二选一式逼问：失速来自 A 还是 B？看量级证据定位真病灶。
- 证伪后**新开一节显式写"部分修正第X部分假说"** + 修正后结论，**禁止回头悄悄改前文**。
- 边界：单点/短窗口/单因子证据须标注，不等同全局铁证；未做的实证列"下一轮"，不脑补。

N=1 范本（量化域）：原假设"失速=动态风格踩错"，实证发现风格守纪律±0.4σ、风格贡献≈0，
真病灶是某域纯选股 alpha 衰减、91% 因子转负 → 显式修正。
